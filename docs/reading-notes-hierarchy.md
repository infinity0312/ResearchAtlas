### 分类层级

原图是论文与标签构成的力导向关系网络，算法不以生成树为目标。当前库中 18 篇论文，只有 1 篇完成当前版本分析；其多个标签会呈现星状关系。综述分类草稿尚未发布，三个领域仍使用手动预设分类。因此不能把图形不成树直接判为分类算法错误，也不能据此认定分类准确性已验证。

新增“领域 → 小方向 → 文献”的可折叠分类树，保留原关系网络用于交叉联系探索。树显示分类来源、版本与已归类数量；待分析或无法确定方向的文献进入单独分支。旧论文版本或旧分类版本结果不会混入当前树。一篇论文可出现在多个方向下，总覆盖数按论文去重。当前最多展示最近 200 篇，可缩小领域与日期范围。

### 笔记系列

全局侧边栏新增“笔记系列”。提供系列组织、标题搜索、新建、归档/恢复、Markdown 文件导入与导出，编辑/双栏/阅读三种模式。

采用 CodeMirror Markdown 编辑器与 CommonMark/GFM 渲染，支持标题、列表、任务清单、表格、代码、脚注、链接以及行内/块级数学公式。支持 `[[笔记标题]]`、`[[笔记标题|显示文字]]` 和已保存笔记的反向链接；同名笔记会提示选择。不会执行原始 HTML 或 javascript 链接。

点击保存或 Ctrl/⌘ S 持久保存至本地 SQLite；正文以 Markdown 原文保存。未保存内容在当前浏览器保留草稿，重开时恢复。使用版本号防止另一窗口的修改被静默覆盖。目录只获取元信息，正文按选中笔记加载，预览延迟更新以减少输入卡顿。

这是借鉴 Obsidian 的 Markdown 工作流，不包含 Obsidian 插件兼容、文件夹双向同步、全库文件监听或同名笔记重命名后的链接自动迁移。可以导出 `.md` 文件继续使用。
