# 统一论文探索工作流

## 使用
首页「论文探索」默认开启检索、抓取、分析、统计。可选择一个或多个领域、开始/结束日期、覆盖领域规则的自定义检索式。原每 24 小时自动同步也使用探索队列：自动分析关闭时只检索与统计；开启时运行全部步骤。

抓取或分析会自动补齐检索与质量初筛，分析会补齐 PDF 获取。统计独立于精读库，缺失范围绝不当作零。界面可查看全部候选按初筛分排序、月度精选、原始评分证据、完成的覆盖区间，并打开对应趋势。

## 数据与恢复
- catalog_papers 保存未精选论文的完整元数据；不会自动进入 papers 精读库。
- search_pages 缓存官方检索分页，search_snapshots 只记录确认完整的范围与论文 ID。
- 完整大范围快照可以复用于其中的较小范围；跨分支按 arXiv ID 去重。历史缓存 7 天，包含当前日期的范围 6 小时。
- exploration_ranks 按元数据、领域规则/分类版本、模型与评分版本复用。PDF、解析文本、有效全文分析分别检查缓存。
- 后台任务按阶段保留进度；失败重试复用已完成的数据。每日全文上限耗尽时进入 waiting，下一 UTC 额度周期自动续做，支持取消。

## 数据来源
优先保留 arXiv API 宏观计数方式；API HTTP 406 时使用官方高级检索 https://arxiv.org/search/advanced 。统一探索使用同一官方历史检索实现：解析现行表单字段，submitted_date_first 按首次提交日过滤，包含跨分类，不含旧版本列表；200 条/页，3.2 秒请求间隔。

Boolean 查询按 DNF 分支执行并去重。支持 cat/all/ti/abs/au 与 AND/OR/ANDNOT。分页重复、记录缺失、总数漂移、无法解析时不标记完整。超过 9500 条的区间递归按日期拆分，单日仍超过上限则要求缩小范围，绝不静默截断。

## 质量优先策略
每个候选均纳入标题与摘要初筛。相关性至少 70，优先级分为新颖性 35% + 验证证据 35% + 潜在价值 30%。每月默认目标 3 篇；最低分默认 70，超过 85 可额外入选，每月上限默认 6，可在弹窗调整。所有已选领域合并后按月选择，不重复抓取同一论文。

分数是基于摘要证据的精读优先级，不等同于经过全文验证的学术质量。模型不能虚构引用量、刊会信息或以作者名气评分。模型选择原摘要的 evidence_index，程序直接保存原文段落作为依据。仅入选论文下载 PDF、解析全部页并执行现有全文证据提取流程；其余保留元数据用于统计与后续复查。
